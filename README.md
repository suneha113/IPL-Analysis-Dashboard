## Overview
This Power BI dashboard provides comprehensive analysis of Indian Premier League (IPL) cricket statistics through the seasons. The dashboard offers insights into team performance, player statistics, and match outcomes.

## Dashboard Features

### Key Metrics (2009 Season shown)
- **Total Matches Played**: 57
- **Total Runs Scored**: 16K
- **Total Wickets Taken**: 698
- **Highest Individual Score**: 626

### Visualizations Include:
1. **Total Runs Scored by Batsman** - Line chart tracking top batsmen performance (ML Hayden, AC Gilchrist, Adam Voges, SK Raina, TM Dilshan, No New Batsman)

2. **Total Wickets Taken by Bowler** - Horizontal bar chart showing leading wicket-takers (PP Singh, A Kumble, A Nehra, PP Ojha, SL Malinga)

3. **Total Wins by Each Team** - Bar chart displaying team performance (Delhi Daredevils, Deccan Chargers, Royal Challengers Bangalore, Chennai Super Kings, Kings XI Punjab, Rajasthan Royals, Mumbai Indians)

4. **Top Venues by Matches Played** - Pie chart showing distribution of matches across venues (Kingsmead, SuperSport Park, and others)

5. **Season Slicer** - Interactive filter to analyze different IPL seasons starting from 2009


## Data Source
The dashboard analyzes IPL match data including batting, bowling, and team statistics across multiple seasons.

## How to Use
1. Download the .pbix file
2. Open it in Power BI Desktop (free version)
3. Use the Season Slicer to explore different years
4. Interact with visualizations to filter and drill down into specific data
